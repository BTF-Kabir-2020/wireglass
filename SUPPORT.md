# Support

Thanks for using WIREGLASS. Here is where to go for help.

## I found a bug

Open an issue using the **Bug report** template. Please include the exact command
you ran, the output (trimmed JSON is fine — redact anything private), your OS,
and `rustc --version`.

## I have an idea or feature request

Open an issue using the **Feature request** template. Explain the problem first,
then the proposed behavior.

## I have a question

Open a regular issue or start a GitHub Discussion (if enabled) with the
**question** label. For usage questions, the exact command and observed output
are the most useful thing you can provide.

## I found a security problem

Do **not** open a public issue. See [SECURITY.md](SECURITY.md).

## What is *not* supported

- **The tool is local-only.** There is no hosted service to support yet; if that
  changes, this file will say so.
- **Not a general-purpose network scanner.** Reports reflect a single run from a
  single vantage point and can be affected by your network; they are not a
  verdict about a website's overall quality.
